# 🎓 ClassGPT

> **Your AI-powered classroom assistant.**

ClassGPT is an AI-powered web application that helps students access everything related to their academics in one place. Instead of searching through PDFs, WhatsApp groups, and notice boards, students can simply ask questions in natural language and receive accurate answers backed by uploaded college resources.

---

# ✨ Features

## 🤖 AI Chat Assistant

Ask questions like:

* What's today's timetable?
* What's the syllabus for DBMS?
* Explain Unit 4 in simple words.
* Generate MCQs from these notes.
* What assignments are pending?
* Has any lecture been shifted today?

---

## 📚 Academic Resources

* Subject-wise Notes
* Syllabus
* Previous Question Papers
* Study Materials
* AI Summaries
* Flashcards
* MCQ Generation

---

## 📢 Notice Assistant

Stay updated with:

* Lecture changes
* Room changes
* Assignment announcements
* Exam notices
* Holiday notices

---

## 📅 Timetable Assistant

Students can instantly ask:

* What's my first lecture tomorrow?
* Which room is today's Python lab?
* What's after lunch today?

---

## 👨‍💼 Admin Dashboard

Authorized users can:

* Upload Notes
* Upload Syllabus
* Upload Timetable
* Upload Notices
* Manage Subjects
* Update Academic Resources
